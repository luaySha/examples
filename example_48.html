Example 48 (Slide 171)

Reconsider the fabrication investment project of Merco Inc. which was introduced in a previous example. (a) What is the projected IRR on this fabrication investment? (b) If Merco’s MARR is known to be 15%, is this investment justifiable? Solution: (a) PW(i*) = − $1,250,000 + $731,500 (P/A, i, 15) + $80,000(P/F, i, 15) = 0 Using web calculator or Excel’s financial function (IRR), we find the IRR to be 58.43% (b) The IRR figure far exceeds the Merco’s MARR (15%), indicating that the fabrication system project is an economically attractive one. 171 Rate of Return Analysis Example
